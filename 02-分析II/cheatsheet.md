## 常用推理链

1. 阶梯函数 → 一致逼近 → 积分 → 基本定理 → 计算。
2. 偏导连续 → 可微 → 雅可比 → 链式 → 逆映射/隐函数。
3. 1-形式 → 闭性检验 → 单连通 → 势函数 → 路径无关。
4. 复可微 → 柯西–黎曼 → 解析 → 柯西定理 → 留数。
