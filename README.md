# 分析 I · II · III 点化学习系统

把 Herbert Amann / Joachim Escher《分析 I、II、III》（方汝见之中译）三卷转成一套可按依赖顺序自学的知识库：12 章零基础精讲、15 个概念页、42 道带解析的测验、60 张抽认卡、88 条术语，收在一个 `index.html` 总入口里，并附每本书的单文件学习伴侣。

## 怎么打开

双击根目录的 `index.html`（单文件、离线可开）。顶部切换「跨书总览 / 分析 I / 分析 II / 分析 III」，左侧按学习路径、章节、概念、测验、抽认卡、术语、模式、速查浏览；右上角有全局搜索与深色模式开关；每本书的进度独立保存在浏览器本地。

三本书也可以单独打开：`01-分析I/analysis-i学习伴侣.html`、`02-分析II/analysis-ii学习伴侣.html`、`03-分析III/analysis-iii学习伴侣.html`，可单独发给别人。

## 推荐顺序

按概念依赖从下往上，不按页序：

1. 《分析 I》第 1–5 章：数系与完备性 → 收敛 → 连续 → 一元微分 → 函数列。
2. 《分析 II》第 6 章：积分（阶梯逼近 + 基本定理）→ 第 7 章 多变量微分 → 第 8 章 线积分与全纯。
3. 《分析 III》第 9 章 测度 → 第 10 章 勒贝格积分 → 第 11 章 微分形式 → 第 12 章 流形积分与斯托克斯。

详细理由与里程碑见 `00-跨书总览/README.md`。

## 部署到 GitHub Pages

```bash
# 1. 把本目录全部文件放到仓库根目录（不是子目录）
cd <仓库目录>
git add -A
git commit -m "点化学习系统：分析 I–III"
git push origin main
```

2. 仓库 Settings → Pages → Source: Deploy from a branch，Branch 选 `main`，目录选 `/ (root)`，Save。
3. 等 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

根目录已有空文件 `.nojekyll`，用于关闭 Jekyll，保证中文文件名与以下划线开头的 `_work/`、`_build/` 原样托管。

### 常见问题

- **404**：确认 `index.html` 在仓库根目录，Pages 源选的是 `main` + `/ (root)`；刚开启要等一会儿。
- **图不显示**：Mermaid 走 CDN，联网才渲染；离线时显示源码并附提示，属预期行为，不是坏了。
- **想减小仓库体积**：`_work/`（抽取原文与摘要）与 `_build/`（构建脚本、验证报告）可以删，不影响站点功能。

## 内容口径

- 面向零基础但保留原书严格性：每个抽象概念至少给类比、图示、实例中的两样，类比均标注失效边界。
- 术语首次出现即给白话定义，并进术语表；不写"显然""不难看出"。
- 测验答案与讲解一一对应；每章 3 题，书末 2 道综合题。
- 章节文本由原书 PDF 抽取后按章重写，不是原文摘抄；引用原书结论处已核对页码。
