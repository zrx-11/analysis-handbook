# 模式与框架库：《分析 I》

## 框架：三段估计

证明极限传递性质时，标准的拆法是

‖A − B‖ ≤ ‖A − C‖ + ‖C − D‖ + ‖D − B‖。

中间项用被逼近对象的性质（连续性、可微性），两端用一致收敛或小参数控制。本章的连续性传递、积分传递都走这个结构。用的时候先问：中间项靠什么控制？两端靠什么统一？

## 框架：先造对象，再证性质

指数函数不是"已知存在"，而是用级数定义出来，再用绝对收敛证明加法定理，最后推出可微与 exp′ = exp。遇到"这个东西到底存不存在"的问题，先找一个可构造的候选（级数、上确界、极限），再逐条验证定义。

## 决策规则

- 要证"存在某个点使 f′ = 0"：先看能不能用紧致性取极值，再用内部极值导数为零。
- 要证"数列收敛"：优先试单调 + 有界；不行再找柯西估计；再不行才猜极限。
- 要证"函数列极限连续"：先确认一致收敛；只有逐点收敛时，改用等度连续或分段讨论。
- 要证"集合不可数"：用对角线构造反例，不要试图逐个列举。

## 反模式

- **用具体 ε 代替任意 ε**。证明里代 0.001 只说明"误差小于 0.001 时成立"，不说明任意 ε。
- **把"任意接近"当成"等于"**。上确界可以不属于集合，极限可以不被取到。
- **逐点收敛直接推极限连续**。必须先升级到一致收敛，否则 xⁿ 就是反例。
- **把导数当差商的近似值**。导数是极限，不是"很小的 h 的差商"，误差项必须显式控制。
