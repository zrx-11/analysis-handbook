# 《分析 I》抽认卡

## 第 1 章：基础
### 卡片：序完备性说的是什么？
- **背面**：每个非空、上有界的子集都有上确界。ℝ 满足，ℚ 不满足。
- **标签**：完备性, 实数
- **章节**：ch01
### 卡片：皮亚诺第 5 条公理的作用？
- **背面**：把“从 0 起逐個到达”变成公理，保证归纳法覆盖整个 ℕ。
- **标签**：自然数, 归纳
- **章节**：ch01
### 卡片：ℚ 中 {x : x² < 2, x > 0} 有上确界吗？
- **背面**：没有。它的上确界是 √2，不在 ℚ 中。
- **标签**：完备性, 反例
- **章节**：ch01
### 卡片：可数与稠密的区别？
- **背面**：可数=存在到 ℕ 的双射；稠密=任意两数之间还有数。ℚ 既稠密又可数。
- **标签**：可数
- **章节**：ch01
### 卡片：数系扩张的统一手法？
- **背面**：造一个更大的集合，再按等价关系取商（如整数用差相同，分数用交叉相乘相等）。
- **标签**：构造
- **章节**：ch01

## 第 2 章：收敛性
### 卡片：ε-N 定义中三个容易忽略的点？
- **背面**：ε 任意；N 依赖 ε；只要求从 N 以后成立。
- **标签**：极限, 定义
- **章节**：ch02
### 卡片：柯西列与收敛列的关系？
- **背面**：收敛 ⇒ 柯西；柯西 ⇒ 收敛只在完备空间成立。
- **标签**：完备性
- **章节**：ch02
### 卡片：单调有界定理为什么好用？
- **背面**：不需要猜极限，只要验证“递增 + 有上界”，收敛性与极限存在性一起得到。
- **标签**：极限
- **章节**：ch02
### 卡片：绝对收敛与条件收敛的差别？
- **背面**：绝对收敛=绝对值级数收敛，可任意重排；条件收敛重排会改变和。
- **标签**：级数
- **章节**：ch02
### 卡片：幂级数的收敛集合形状？
- **背面**：以展开点为心的圆盘；半径由 1/R = limsup |aₙ|^(1/n) 给出。
- **标签**：幂级数
- **章节**：ch02

## 第 3 章：连续函数
### 卡片：连续性的开集刻画？
- **背面**：f 连续 ⇔ 每个开集的原像是开集。
- **标签**：连续, 拓扑
- **章节**：ch03
### 卡片：紧致性的两条等价说法（度量空间）？
- **背面**：开覆盖有有限子覆盖；每个序列有收敛子列。
- **标签**：紧致
- **章节**：ch03
### 卡片：为什么紧集上连续函数一致连续？
- **背面**：若没有统一 δ，可取 xₙ、yₙ 距离趋 0 而函数值差 ≥ ε，紧性抽出共同极限点，与连续性矛盾。
- **标签**：紧致, 一致连续
- **章节**：ch03
### 卡片：介值定理对复值函数成立吗？
- **背面**：不成立。值域必须是一维有序的；复值可以绕圈避开中间值。
- **标签**：介值
- **章节**：ch03
### 卡片：exp 怎么定义？
- **背面**：exp(z) = Σ zⁿ/n!，绝对收敛；由柯西乘积得加法定理。
- **标签**：指数函数
- **章节**：ch03

## 第 4 章：一元微分学
### 卡片：可微的线性逼近说法？
- **背面**：存在仿射 g 使 f(a)=g(a) 且 ‖f(x)−g(x)‖/|x−a| → 0。
- **标签**：微分
- **章节**：ch04
### 卡片：罗尔定理的证明关键？
- **背面**：紧区间上连续函数取到极值；内部极值处导数为 0；端点极值则函数为常数。
- **标签**：中值定理
- **章节**：ch04
### 卡片：泰勒两种余项各适合什么？
- **背面**：皮亚诺余项适合求极限；拉格朗日余项给出具体误差界。
- **标签**：泰勒
- **章节**：ch04
### 卡片：牛顿法何时退化？
- **背面**：f′ 接近 0、根为重根、初值不在吸引域时；收敛从二次退化为线性或发散。
- **标签**：迭代
- **章节**：ch04
### 卡片：f′(a)=0 一定是极值吗？
- **背面**：不一定。x³ 在 0 处导数为 0 但不是极值。
- **标签**：极值
- **章节**：ch04

## 第 5 章：函数序列
### 卡片：逐点与一致收敛的唯一差别？
- **背面**：N 是否依赖 x。一致收敛的 N 只依赖 ε。
- **标签**：一致收敛
- **章节**：ch05
### 卡片：一致收敛能传递微分吗？
- **背面**：不能，除非导数列也一致收敛，且原列在某点收敛。
- **标签**：一致收敛, 微分
- **章节**：ch05
### 卡片：M-判别法说什么？
- **背面**：若 ‖fₙ‖∞ ≤ Mₙ 且 ΣMₙ 收敛，则 Σfₙ 一致且绝对收敛。
- **标签**：级数, 一致收敛
- **章节**：ch05
### 卡片：解析与 C∞ 的区别？
- **背面**：解析要求局部等于幂级数；C∞ 只要求无穷次可微。e^(−1/x²) 是 C∞ 但不解析。
- **标签**：解析
- **章节**：ch05
### 卡片：魏尔斯特拉斯逼近定理？
- **背面**：紧区间上连续函数可用多项式一致逼近（Bernstein 多项式给出构造）。
- **标签**：逼近
- **章节**：ch05
