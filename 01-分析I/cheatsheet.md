# 速查表：《分析 I》

## 定义与公式

| 场景 | 内容 |
|---|---|
| 上确界 | sup A 是最小上界；序完备：非空上有界必有 sup |
| 收敛 | ∀ε>0 ∃N ∀n≥N：‖xₙ − a‖ < ε |
| 柯西 | ∀ε>0 ∃N ∀m,n≥N：‖xₘ − xₙ‖ < ε |
| 完备 | 柯西列必收敛；ℝ、ℂ、Banach 空间完备 |
| 级数收敛 | 部分和 sₙ = Σxₖ 收敛；正项级数收敛 ⇔ 部分和有界 |
| 幂级数半径 | 1/R = limsup |aₙ|^(1/n) |
| 连续 | ∀ε>0 ∃δ>0：d(x,x₀)<δ ⇒ d(f(x),f(x₀))<ε |
| 一致连续 | ∀ε>0 ∃δ>0 ∀x,y：d(x,y)<δ ⇒ d(f(x),f(y))<ε |
| 紧致 | 开覆盖有有限子覆盖 ⇔ 序列有收敛子列（度量空间） |
| 导数 | f′(a) = lim (f(x)−f(a))/(x−a) |
| 拉格朗日中值 | f(b)−f(a) = f′(ξ)(b−a)，ξ ∈ (a,b) |
| 泰勒（拉格朗日余项） | Rₙ = f⁽ⁿ⁺¹⁾(ξ)(x−a)ⁿ⁺¹/(n+1)! |
| 牛顿迭代 | xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ)，单根处二次收敛 |
| 一致收敛 | sup_x ‖fₙ(x)−f(x)‖ → 0 |
| M-判别法 | ‖fₙ‖∞ ≤ Mₙ 且 ΣMₙ < ∞ ⇒ Σfₙ 一致收敛 |

## 常用推理链

1. 上有界 → 上确界 → 单调列收敛 → 极限存在。
2. 闭区间 → 紧致 → 连续函数取极值 → 罗尔 → 中值定理。
3. 一致收敛 → sup 误差 → 连续/积分传递；导数另需导数列一致收敛。
4. 幂级数 → 紧子集一致收敛 → 逐项求导 → 解析。
