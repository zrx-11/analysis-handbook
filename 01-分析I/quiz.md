# 《分析 I》测验

## 第 1 章：基础测验（检查点）
### Q1.（单选）下列哪个集合在 ℚ 中没有上确界？

A. {x ∈ ℚ : x < 1}　B. {x ∈ ℚ : x² < 2 且 x > 0}　C. {x ∈ ℚ : 0 ≤ x ≤ 1}　D. {x ∈ ℚ : x² < 4 且 x > 0}

**答案**：B

**解析**：前三个的上确界分别是 1、1、2，都在 ℚ 中。第二个集合的上确界是 √2，不在 ℚ 中；书中用 ξ = (2c+2)/(c+2) 证明任何有理上界都能被改进。
### Q2.（单选）皮亚诺公理中，哪一条保证数学归纳法可用？

A. 0 ∈ ℕ　B. 后继是单射　C. 归纳公理（第 5 条）　D. 0 不是任何数的后继

**答案**：C

**解析**：前四条只刻画后继链，第 5 条排除“链外还有多余元素”的模型，归纳才能覆盖整个 ℕ。
### Q3.（单选）关于集合的可数性，下列判断正确的是？

A. ℚ 不可数　B. ℝ 可数　C. ℤ 与 ℚ 都可数　D. 有限集不可数

**答案**：C

**解析**：ℤ 可按 0,1,−1,2,−2,… 排队；ℚ 可按 |p|+q 分层排队。ℝ 由康托对角线不可数，有限集按定义可数。

## 第 2 章：收敛性测验（检查点）
### Q1.（单选）数列 xₙ = (−1)ⁿ 的收敛情况是？

A. 收敛到 1　B. 收敛到 −1　C. 不收敛　D. 收敛到 0

**答案**：C

**解析**：取 ε₀ = 1，任何 N 之后都能找到奇偶两项，距离为 2，不满足柯西条件，因此不收敛。
### Q2.（单选）下列空间中，哪一个在通常度量下不完备？

A. ℝ　B. ℂ　C. ℚ　D. ℝ²

**答案**：C

**解析**：√2 的截断小数是 ℚ 中的柯西列，但极限不在 ℚ 中。ℝ、ℂ、ℝ² 都完备。
### Q3.（单选）关于级数，正确的说法是？

A. 通项趋于 0 则级数收敛　B. 在巴拿赫空间中绝对收敛必定收敛　C. 条件收敛的级数重排后仍收敛到同一值　D. 收敛级数必定绝对收敛

**答案**：B

**解析**：A 错，调和级数通项趋于 0 却发散；C 错，重排可改变和甚至发散；D 错，交错调和级数收敛但绝对值级数发散。

## 第 3 章：连续函数测验（检查点）
### Q1.（单选）f(x) = 1/x 在 (0, 1) 上的一致连续性如何？

A. 一致连续　B. 连续但非一致连续　C. 不连续　D. 只在 (1/2,1) 上一致连续

**答案**：B

**解析**：取 xₙ = 1/n，yₙ = 1/(n+1)，两点距离趋于 0，函数值之差恒为 1，不存在统一 δ。定义域不紧致，正是一致连续失效的典型场景。
### Q2.（单选）下列哪个条件能保证连续函数 f : X → ℝ 取到最小值？

A. X 是开区间　B. X 紧致　C. f 有界　D. X 连通

**答案**：B

**解析**：紧集上连续函数取到最大最小值。开区间、连通都不够（f(x)=x 在 (0,1) 无最小值）；仅有界也不够。
### Q3.（单选）介值定理成立的必要条件不包括？

A. 定义域连通　B. 函数连续　C. 值域是一维有序的　D. 函数可微

**答案**：D

**解析**：介值定理只用连续性，不要求可微。去掉连通、去掉连续、或换成复值，结论都会失效。

## 第 4 章：一元微分学测验（检查点）
### Q1.（单选）f(x) = |x| 在 x = 0 处？

A. 可微且导数为 0　B. 连续但不可微　C. 不连续　D. 可微但导数不存在

**答案**：B

**解析**：左右差商分别为 1 和 −1，极限不存在，所以不可微；但函数本身连续。
### Q2.（单选）设 f 在 [0, 2] 上可微，f(0) = 0，f(2) = 4，则一定能推出？

A. 存在 ξ 使 f′(ξ) = 2　B. f′ 处处等于 2　C. f 单调递增　D. f″ 存在

**答案**：A

**解析**：拉格朗日中值定理给出 f(2) − f(0) = f′(ξ)(2 − 0)，即 f′(ξ) = 2。其余三项都不保证。
### Q3.（单选）用牛顿法求 f(x) = x² − 2 的正根，初值 x₀ = 1，迭代式是？

A. xₙ₊₁ = (xₙ + 2/xₙ)/2　B. xₙ₊₁ = xₙ − xₙ²　C. xₙ₊₁ = 2/xₙ　D. xₙ₊₁ = xₙ + 1

**答案**：A

**解析**：x − f/f′ = x − (x² − 2)/(2x) = (x + 2/x)/2，这是求平方根的标准迭代，误差平方级下降。

## 第 5 章：函数序列测验（检查点）
### Q1.（单选）fₙ(x) = xⁿ 在下列哪个区间上一致收敛到 0？

A. [0,1]　B. [0,1)　C. [0, 0.9]　D. (−1,1]

**答案**：C

**解析**：在 [0,1] 上极限函数在 1 处跳到 1，不一致；[0,0.9] 上 sup|fₙ| ≤ 0.9ⁿ → 0，一致收敛。
### Q2.（单选）若 fₙ 一致收敛到 f，且每个 fₙ 连续，则？

A. f 一定可微　B. f 一定连续　C. fₙ′ 一定一致收敛　D. f 一定有界

**答案**：B

**解析**：一致收敛传递连续性。可微、导数收敛都不保证；f 在有界区间上才有界，题干没说 X 有界。
### Q3.（单选）关于解析函数，正确的说法是？

A. 解析与 C∞ 等价　B. 解析函数在收敛圆内可逐项求导　C. 解析函数的泰勒级数处处收敛到自身　D. 解析函数一定是有理函数

**答案**：B

**解析**：A 错，e^(−1/x²) 是 C∞ 但不解析；C 错，只在收敛圆内；D 错，exp、sin 都是超越函数。

## 综合测验（多章联考）
### Q1.（单选）设 fₙ(x) = xⁿ 在 [0,1] 上。下列说法正确的是？

A. 一致收敛且极限连续　B. 逐点收敛但极限不连续，说明逐点收敛不足以保证连续性传递　C. 不逐点收敛　D. 一致收敛但极限不连续

**答案**：B

**解析**：每点收敛到 0（x<1）或 1（x=1），极限在 1 处跳跃。每条 fₙ 连续，极限不连续，正好说明连续性传递需要一致收敛。
### Q2.（填空）计算 sup{1 − 1/n : n ∈ ℕ, n ≥ 1}，填数值。

**答案**：1

**解析**：集合单调递增趋近 1，且每项都小于 1，所以 1 是最小上界；它不在集合内，说明上确界不必是集合的元素。

## 最终检验
取 f(x) = x² 在 [0,2] 上，完成四步：证明一致连续；求最大值并说明用了哪条定理；写出在 1 处带拉格朗日余项的二阶泰勒公式；用余项估计 |x−1| ≤ 0.1 时的误差上界。评分要点：每步标明依据的定理，误差界要有具体数值。
