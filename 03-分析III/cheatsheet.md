# 速查表：《分析 III》

## 定义与公式

| 场景 | 内容 |
|---|---|
| σ-代数 | 含 X；对补集封闭；对可数并封闭 |

## 常用推理链

1. 覆盖 → 外测度 → 卡拉泰奥多里 → 测度 → 可测函数 → 积分。
2. 简单函数 → 单调收敛 → 一般积分 → L1 完备化 → Lp。
3. 度量 → 格拉姆矩阵 → 体积元 → m-形式积分 → 斯托克斯。
4. dω=0 → 闭；星形区域 → 恰当；有洞 → 积分非零（拓扑）。
